# 中央研究院百周年院慶 標語徵選網頁（RWD 響應式版本）

本專案係依據中央研究院秘書處設計之百年院慶標語徵選視覺（`ChatGPT Image 2026年9月14日 上午11_34_57.png`）與《百年院慶標語公開徵選網頁需求說明書》所量身打造的**現代化純靜態 RWD 官方活動網站**。

---

## 🌟 核心特色與成果

1. **極致視覺還原度（Desktop 1:1 完美還原）**：
   - 桌面端完整呈現秘書處設計的主視覺構圖：左側百年 100 紀念徽飾（深緋紅 1、金質 DNA 環、金色月桂葉、行星軌道金珠與絲帶雙環）、右側南港院區蓊鬱山巒空拍圖（遠眺台北 101）及百年精神標語。
   - 畫面中的按鈕「**我要投稿**」與「**徵選辦法**」具備高精準度互動熱區、緋紅漸層光暈與金色外框微動畫。

2. **完整 RWD 跨裝置響應式架構（Mobile & Tablet）**：
   - **手機與平板端（寬度 ≤ 1024px / 直式畫面）**：自動切換為專屬行動佈局。百周年 100 徽飾置頂亮相，大器標題採用 Google Fonts 思源宋體（`Noto Serif TC`）與經典襯線字體（`Cinzel`），按鈕放大為觸控友善的滿版膠囊造型。
   - **手機端常駐浮動列（Floating Sticky CTA）**：手機滑動瀏覽時，頁面下方自動常駐「我要投稿」與「徵選辦法」快捷列，同仁隨時皆可一鍵直達投稿表單。

3. **超連結導向 Google 表單（Google Forms 整合）**：
   - 全站所有「我要投稿」按鈕（頂部導覽列、主視覺按鈕、卡片按鈕、頁尾按鈕、彈跳視窗、手機常駐列）皆已綁定至投稿表單超連結。
   - 預設提供連結：`https://forms.gle/MJkYBRTb5NpWaSAZ6`。

4. **完整活動內容與彈出式視窗（Modal Dialog）**：
   - 點擊「**徵選辦法**」即跳出高質感毛玻璃光暈視窗，詳細說明投稿規格（中文20字內、英文15字詞內、理念300字內）、秒級時間戳記優先入圍依據、身分資格（限現職同仁）、雙盲審查等。
   - 往下滾動包含：**活動三大核心重點卡片**、**活動重要推展時程軸**、**詳細徵選辦法規格表**、**常見問答（FAQ）手風琴展開收合**及**主辦單位資訊頁尾**。

5. **純 HTML/CSS/JS，高相容零負擔**：
   - 無需 Node.js 或複雜編譯環境，雙擊 `index.html` 即可直接於瀏覽器離線預覽，或直接上傳至任何院內 Web 伺服器、Apache、Nginx、IIS 或雲端靜態空間。

## 🔧 如何更換 Google 表單投稿連結？

最推薦的方式：直接到 Google 試算表「全站與主視覺」分頁，修改 `submit_form_url` 這一列的中文/英文內容欄位即可，儲存後全站按鈕會自動同步（見下方「Google 試算表 CMS」說明）。

（`index.html` 內也保留了一組寫死的 `GOOGLE_FORM_URL` 常數作為最後備援，僅在試算表完全連不上時才會用到，一般情況不需要修改它。）

## 📊 Google 試算表 CMS：讓網站上所有文字都能用 Excel 修改

本網站的文字內容由 `assets/cms.js` 在頁面載入時，即時向 Google 試算表讀取資料並覆寫畫面（透過 Google 內建的 `gviz` 公開 JSON API，不需要任何後端伺服器）。試算表共有 5 個分頁，各自對應網站上的一個區塊：

| 試算表分頁 | 對應網站區塊 |
|---|---|
| 全站與主視覺 | 導覽列、首頁主視覺、頁尾（品牌、快速連結、聯絡資訊、版權）、各區塊標題/說明、彈窗標題與提示文字 |
| 活動重點與獎勵 | 「活動三大核心重點」卡片 |
| 重要時程 | 「活動推展重要時程」時間軸（含圓圈徽章文字） |
| 徵選辦法彈窗 | 「詳細徵選辦法與規範」區塊 ＋ 徵選辦法彈出視窗 |
| 常見問題與Footer | FAQ 手風琴 ＋ 頁尾社群連結 |

若某個儲存格留空，網站會自動使用內建的預設文字，不會顯示空白，所以**新增列或新增欄都是安全、不會弄壞畫面的操作**。網頁每次載入都會重新抓取試算表最新內容，同仁編輯試算表後，訪客重新整理網頁（或等待約數秒快取更新）即可看到最新文字。

### ⚠️ 若你發現「並非所有文字都能修改」

早期版本中，下列內容雖然在試算表裡有欄位，但網站程式碼其實沒有真正讀取它們，所以無論怎麼編輯試算表都不會反映到網站上：

- 頁尾（品牌名稱、快速連結、聯絡資訊、版權、投稿表單提示）
- 頁尾行動呼籲橫條（CTA Banner）的標題／說明／按鈕文字
- 「重要時程」時間軸圓圈徽章上的月份/日期文字（過去是寫死在程式碼裡，與「時程區間」欄位的內容無關）
- 4 個區塊的標題與副標題（活動三大核心重點／重要時程／詳細徵選辦法／常見問答）
- 徵選辦法彈窗的標題、頂部提示框文字、關閉/投稿按鈕文字

這些已在最新版的 `assets/cms.js`、`index.html` 中修正並接上試算表。**若你要讓已修正的欄位在試算表中也能真正編輯，需要在「全站與主視覺」分頁補上新的設定列，並在「活動重點與獎勵」「重要時程」分頁補上新的欄位**，作法如下：

> 註：頁尾上方原本的「行動呼籲橫條」（深酒紅底、含 `cta_banner_title`／`cta_banner_desc`／`cta_banner_btn` 等欄位的整段區塊）已依需求移除，不再顯示於網站上。試算表裡若還留著這幾個 key 的列，不會造成任何問題（網站不會再讀取它們），可以留著或刪除都可以。

#### 作法一：手動在既有試算表新增（推薦，不會清空現有資料）

1. 開啟「全站與主視覺」分頁，在最後一列下方，依照 `google_sheets_setup.gs` 第 41-67 行新增的設定項目（如 `section_highlights_title`、`footer_brand_title`、`dialog_notice`……等），逐列新增「設定項目代碼／中文內容／英文內容」。
2. 開啟「活動重點與獎勵」分頁，在 J 欄之後新增 2 欄：「條列重點 (中)」「條列重點 (英)」，選填，每行一條會顯示為卡片條列清單。
3. 開啟「重要時程」分頁，在 J 欄之後新增 4 欄：「圓圈徽章大字 (中)」「圓圈徽章大字 (英)」「圓圈徽章小字 (中)」「圓圈徽章小字 (英)」，選填，用來控制時間軸圓圈內顯示的文字（例如「10月」「01日」）。

新增內容的確切文字建議，可參考 `google_sheets_setup.gs` 檔案中對應的預設值。

#### 作法二：重新執行 Apps Script（會清空並重建所有 5 個分頁，請先確認沒有想保留的手動編輯內容）

在 Google 試算表中點選「擴充功能」→「Apps Script」，貼上最新版 `google_sheets_setup.gs` 的內容並執行 `setupCentennialSloganSheets`。**此方式會把 5 個分頁全部清空並以程式碼中的內容重建，任何先前手動編輯過但未同步回程式碼的內容都會遺失**，僅建議在試算表尚未有重要手動編輯，或已先備份（檔案 → 建立副本）的情況下使用。

## 🚀 部署與上線方式

1. 將 `index.html` 及 `assets` 資料夾一同複製至目標網站目錄下即可。
2. 可直接支援 HTTPS 加密連線、各家現代瀏覽器（Chrome、Edge、Safari、Firefox）及行動裝置（iOS Safari、Android Chrome）。
