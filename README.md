# 中央研究院百年院慶 標語徵選網站

本專案是為「中央研究院百年院慶標語公開徵選活動」打造的**純靜態 RWD 網站**，內容全部透過 Google 試算表管理，不需要資料庫或後端伺服器。除了公開的活動官網之外，也內建了一套**匿名評審評分系統**。

---

## 🌐 網站有哪些功能／頁面

### 1. 活動官網（`index.html`）— 給所有同仁看的公開頁面
- 首頁主視覺（桌機為整合設計圖，手機/平板改為文字排版）＋「我要投稿」「徵選辦法」按鈕
- 最新消息公告區塊
- 活動推展重要時程軸
- 常見問答（FAQ 手風琴）
- 徵選辦法彈出視窗（投稿規格、資格、審查方式說明）
- **入圍名單公告**：卡片式呈現中英文標語＋創作理念說明，超過 5 筆自動分頁
- **得獎公告**：同入圍名單的卡片呈現方式（目前預設關閉，可在試算表開啟）
- 頁尾（機構資訊、聯絡方式、社群/官網連結圖示）
- 全站文字（標題、說明、開關）都可透過 Google 試算表即時修改，不需要改程式碼

### 2. 評審評分系統（`judge.html`）— 目前仍然存在，功能正常
每位評審委員有一組專屬的**匿名網址**（`judge.html?c=你的專屬代碼`），特色：
- **不需要登入帳號**，也不需要記密碼，靠網址裡的隱藏代碼識別身分
- 評審只看得到「入圍名單公告」的**排序、中英文標語、創作理念說明**，**完全看不到投稿人的所別／姓名／SSO** 等任何個資（雙盲評選，就算用瀏覽器開發者工具檢查網路請求也看不到）
- 評審之間**互相看不到彼此的分數**
- 每位評審可對每件作品打分數，可隨時回來修改，分數即時寫回一份**獨立、非公開**的評分試算表

### 3. 評分結果總表（`results.html`）— 給主辦方彙整結果用
- 彙整所有評審的分數，依總分排序
- 可切換「總表」（只看總分排名）／「明細」（展開看每位評審各自給幾分）
- 支援搜尋、CSV 匯出（含創作理念全文，方便離線整理）
- 這頁同樣不會顯示投稿人個資

> 換句話說：**評分功能還在，是完整可用的**，`judge.html`／`results.html` 都在專案資料夾裡，且已串好正式的 Google 試算表與 Apps Script 後端。

## 📊 Google 試算表 CMS（公開內容）

正式試算表：
`https://docs.google.com/spreadsheets/d/10cFGVyCSQqGEPjWw7LBs1xs9hevCXWpUfoV2DhU8qYU/edit`

網站在每次載入時，即時向這份試算表讀取內容（透過 Google 內建的 `gviz` 公開 JSON API），共有 8 個分頁：

| 試算表分頁 | 對應網站區塊 |
|---|---|
| 全站與主視覺 | 導覽列、首頁主視覺文字、投稿表單連結、入圍/得獎名單各欄位顯示開關、彈窗文字、頁尾資訊 |
| 各區塊設定 | 各區塊（最新消息／時程／FAQ／入圍名單／得獎公告）的標題、說明、顯示順序、顯示開關——**一個區塊的所有設定集中在同一列**，方便一次調整 |
| 最新消息 | 首頁「最新消息」公告卡片 |
| 重要時程 | 「活動推展重要時程」時間軸 |
| 徵選辦法彈窗 | 徵選辦法彈出視窗內文各章節 |
| 常見問題與Footer | FAQ 手風琴內容 ＋ 頁尾社群/官網連結圖示（列類別選「Footer連結」） |
| 入圍名單公告 | 入圍名單卡片（含所別/姓名/SSO 顯示開關、創作理念說明） |
| 得獎公告 | 得獎名單卡片（結構同入圍名單） |

若儲存格留空，網站會自動顯示內建的預設文字，不會顯示空白——**新增列或修改內容都是安全的操作**。

## 🔒 評分系統的資料與安全性

評分系統刻意跟公開試算表**分開兩份**，避免評審身分或分數外流到公開網站：

- **公開試算表**（上面那份）：只放「入圍名單公告」讓評審讀取標語內容，評審看不到投稿人身分欄位。
- **評分試算表**（私人、不公開分享）：存放每位評審的分數，由 `judge_scoring_backend.gs` 這支 Apps Script 讀寫。
- `judge_scoring_backend.gs` 內含每位評審的**真實對應姓名與專屬代碼**，已加入 `.gitignore`，**不會、也不可以**上傳到 GitHub。
- `judge.html` / `results.html` 都是公開檔案（有進版控），但只包含連線用的網址與試算表 ID，本身不含任何委員個資。

**如果之後要換評審名單、重新部署後端**，需要：
1. 修改本機 `judge_scoring_backend.gs` 的 `JUDGES` 對照表
2. 到 Google Apps Script 專案「管理部署作業 → 編輯 → 新版本」重新部署（**不要用「新增部署作業」**，那樣網址會變，`judge.html`/`results.html` 裡貼的網址就會失效）
